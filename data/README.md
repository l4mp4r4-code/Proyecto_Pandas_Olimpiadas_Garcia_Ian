# Conjunto de Datos: 120 años de Historia Olímpica

Por políticas de buenas prácticas y control de versiones, los archivos originales en formato CSV no se incluyen directamente en este repositorio.

## Instrucciones de descarga y ubicación

1. Descarga el conjunto de datos **120 years of Olympic history: athletes and results** desde Kaggle:
   - Enlace: https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results
2. Extrae los archivos descargados y ubica los siguientes dos archivos dentro de esta misma carpeta (`data/`):
   - `athlete_events.csv`
   - `noc_regions.csv`
